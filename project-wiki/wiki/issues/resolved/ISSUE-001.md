## 증상
- PRD 기본값 + 보상 정규화로 1M 학습, 3 시드 eval: −74.7 / −84.3 / −101.1
- 학습 곡선: 10만 스텝에 +8 → 이후 하락해 −60 대 고착 (PRD 리스크 "50만 스텝 후에도 0 이하"에 해당)
- 에러·NaN 없음. 손실·KL 정상 범위 → 전형적인 "조용한 실패"

## 원인 분석
1. **γ=0.99 → 유효 지평 ≈ 100 스텝.** 착륙 보너스(+100)는 수백 스텝 뒤라 할인되면 작고, 추락(−100)은 가깝다 → 떠 있기가 지역적으로 안전.
2. **롤아웃 128 스텝 ≪ 에피소드 길이(수백~1000).** GAE 가 대부분 V 부트스트랩에 의존 → 지평을 늘려도(γ 0.999) 분산만 커짐.
3. **가치 손실 클리핑 ε=0.2** 가 리턴 스케일 수백의 critic 학습을 늦춤 (Atari 보상 클리핑 환경 기준 값).
4. 보상 정규화는 작은 배치·γ0.99 조건에선 손해였으나, 1~3 해결 후에는 이득(+12.8) — 조건 의존.

## 해결 방법
`configs/default.json` / `DEFAULTS` 를 ADR-005 값으로 변경. 구현 코드의 PPO 로직은 바꾸지 않음
(추가된 것은 스위치 `bootstrap_truncation` 뿐, 기본 off).

## 재발 방지
- 새 환경(트레이딩 등)으로 갈 때: **에피소드 길이 대비 롤아웃 길이**와 **1/(1−γ)** 를 먼저 계산.
- "안 배울 때"는 원본 구현을 같은 조건으로 돌려 구현/설정 문제를 먼저 가른다 → [testing/strategy.md](../../testing/strategy.md)
- `episodic_length` 와 truncation 비율을 항상 같이 본다 → `scripts/summarize_runs.py` 에 trunc% 컬럼.
