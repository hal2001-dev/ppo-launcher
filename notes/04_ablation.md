# 04. 구성 요소 제거 실험

**날짜**: 2026-10-28 · 기준 설정 `configs/default.json` · 시드 0/1/2 · 2M 스텝 · 평가 argmax 100ep
상세 경과·1차 배치·해석: `project-wiki/wiki/experiments/EXP-008-ablation.md`

## 설정 파일
| 실험 | 파일 | 변경 키 |
|---|---|---|
| GAE 제거 | `configs/ablation_no_gae.json` | `use_gae=false` → A = G − V (부트스트랩 MC) |
| 보상 정규화 제거 | `configs/ablation_no_reward_norm.json` | `norm_reward=false` |
| 클리핑 제거 | `configs/ablation_no_clip.json` | `clip_policy=false` → L = −r·A (가치 클리핑은 기본부터 off) |

## 결론
1. **GAE**: 최종 결정적 정책은 비슷하지만 학습 중 성능(확률적 정책)이 200 에 못 미침, 곡선 면적 1/4. GAE 는 어드밴티지 분산을 줄여 *학습 과정*을 안정시킨다.
2. **보상 정규화**: 여기선 +12.8 이득 + 시드 편차 감소. 단 4×128·γ0.99 조건에선 손해였다 → 효과는 다른 하이퍼파라미터에 의존.
3. **클리핑**: 평균은 오히려 좋고 3배 빨리 수렴하지만 KL 이 8배. 보상 정규화가 없는 조건에선 3 시드 중 2 개가 실패(최저 4.8점) → 클리핑은 평균 성능이 아니라 **최악의 경우를 막는 장치**.
